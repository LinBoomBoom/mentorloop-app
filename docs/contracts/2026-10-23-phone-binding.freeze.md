## 0.1 撤销记录（2026-10-26）

- 原因：小程序为个人主体，无法申请腾讯云短信签名（2025-09-18 起不再支持个人认证自用签名），也无法使用微信手机号快速验证组件；短信通道不可用。
- 处置：**移除 `/membership/order` 的「未绑定手机号返回 409 / 40902」前置校验**，购买不再要求绑定手机号；移除客户端绑定半屏层与 `bindPhone` / `fetchMyPhone` 封装。
- 保留：`/me/phone` GET / POST 端点与 `bindPhoneToUser` 服务逻辑（服务端不再作为购买门控；App 端将来若需要绑定可复用）。
- 登录：小程序不再自动静默登录，改为用户在登录层主动勾选协议后点击「微信登录」。

## 0. 随设计稿落定的三项决策

| 决策       | 结论                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 采集时机   | 支付前采集：未绑定手机号不创建订单                                    |
| 冲突处理   | 不覆盖原账号：提示更换手机号或联系客服                                |
| 手机号用途 | 会员权益发放与售后凭证；不作为小程序登录凭证（MP 仍 openid 静默登录） |

## 1. 端点变更

| 端点                | 方法 | 变更                                       |
| ------------------- | ---- | ------------------------------------------ |
| `/me/phone`         | GET  | 新增：查询当前账号绑定手机号               |
| `/me/phone`         | POST | 新增：把手机号绑定到当前登录 uid（不切号） |
| `/membership/order` | POST | 新增前置校验：未绑定手机号返回 409         |

## 2. 端点契约（逐字）

```
GET /me/phone                 （requireAuth）
成功：{ "code": 0, "data": { "phone": string | null }, "message": "" }
  未绑定 → phone = null
错误：未登录 / token 失效 → 401
```

```
POST /me/phone                （requireAuth；JSON）
请求体：{ "phone": string(11), "code": string(6) }

成功：{ "code": 0, "data": { "phone": string }, "message": "" }
  - code 为已验证且未消费的短信验证码；成功后该验证码置为已消费
  - 手机号已属于当前账号 → 幂等返回 200（不校验验证码、不改归属）

错误：
  未登录 / token 失效                       → 401
  phone 非 11 位                            → 400 "手机号格式不正确"
  验证码不存在 / 过期 / 已消费 / 不匹配      → 400 "验证码不正确或已过期"
  15 分钟内失败次数超限                      → 400 "尝试过于频繁，请稍后再试"
  手机号已绑定其他账号                       → 409（业务码 40901）"该手机号已绑定其他账号"
```

```
POST /membership/order        （requireAuth；同既有契约，仅新增校验）
新增错误：
  当前账号未绑定手机号 → HTTP 409，body { "code": 40902, "message": "请先绑定手机号后再购买" }
```

## 3. 业务码新增

| 业务码 | HTTP | 含义                 | 客户端处置                                |
| ------ | ---- | -------------------- | ----------------------------------------- |
| 40901  | 409  | 手机号已绑定其他账号 | 停在绑定半屏层，提示更换手机号 / 联系客服 |
| 40902  | 409  | 下单账号未绑定手机号 | 打开绑定半屏层；不得走「重登重试」分支    |

既有 `409`（业务码 409）仍表示微信会话过期，客户端继续走重登重试，语义不变。

## 4. 字段 diff

| 字段                                  | 变更前                | 变更后                          | 端              |
| ------------------------------------- | --------------------- | ------------------------------- | --------------- |
| `GET /me/phone → data.phone`          | 不存在                | `string \| null`                | server → client |
| `POST /me/phone → body.phone/code`    | 不存在                | `string`，必填                  | client → server |
| `POST /me/phone → data.phone`         | 不存在                | `string`（明文，仅本人）        | server → client |
| `POST /membership/order` 未绑定错误码 | 不存在                | 业务码 40902                    | server → client |
| 客户端请求错误对象 `code`             | 仅 message/statusCode | 新增 `code`（透出服务端业务码） | client 内部     |
