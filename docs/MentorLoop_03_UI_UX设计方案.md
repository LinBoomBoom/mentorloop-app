# MentorLoop AI 面试产品：UI/UX 设计方案

## 1. 体验原则

1. **降低面试焦虑，不降低面试标准**：反馈具体、克制、有行动建议。
2. **任务优先于装饰**：面试房间中只保留用户当前需要的信息。
3. **反馈可解释**：评分、报告和推荐题必须能显示依据。
4. **移动端单手可用**：关键操作位于拇指热区；长内容支持分段和保存。
5. **隐私透明**：录音状态、上传状态、保存期限和删除入口可见。

## 2. 视觉方向

- 气质：沉稳、专业、克制；避免“AI 炫技感”压过用户表达。
- 主色：深海军蓝作为面试房间背景，紫蓝作为智能状态色，青绿色表示完成或可靠。
- 面试房间：低干扰深色；普通学习页使用浅色背景，降低长时间阅读疲劳。
- 字体：中文系统字体优先；正文最小 14–16px 等效字号，关键结论不小于 18px。
- 动效：用于传达状态变化，非装饰。默认尊重系统“减少动态效果”设置。

## 3. 页面结构

### 首页

- 首屏主任务：“开始一次面试”。
- 显示当前岗位、最近报告、下一项训练任务。
- 次级入口：专项训练、简历优化、成长档案。

### 面试准备页

- 选择岗位、公司类型、面试时长和难度。
- 显示本次覆盖能力及预计题目数。
- 展示麦克风、网络、录音授权检测；未通过时给出解决路径。

### 面试房间

```text
顶部：退出 / 网络状态 / 剩余时间
中部：数字人角色与简洁环境
下部：当前问题字幕、实时转写、回答状态
底部：录音按钮 / 暂停 / 文字辅助 / 帮助
```

- 用户回答时，数字人进入倾听状态；实时转写仅显示稳定文本，避免文字频闪。
- 不显示“实时评分”，避免打断表达和造成焦虑。
- 网络异常时显示明确恢复状态，而非无响应加载。

### 报告页

- 第一屏只给用户最需要的三件事：总体判断、最强项、最高优先级改进项。
- 之后依次展示能力雷达、题目证据卡、风险问题、优秀回答结构、训练计划。
- 每条建议都提供“去训练”“查看题目”“再次模拟”操作。

### 简历优化页

- 左侧或上方显示原句；下方显示建议版本与修改原因。
- 所有 AI 改写均标记为“建议稿”，用户确认后才保存。
- 对可能虚构的数据使用醒目标记，提示用户补充真实证据。

## 4. 关键交互规范

- 面试结束必须二次确认，防止误触；异常退出自动保存会话。
- 麦克风权限拒绝后，说明去系统设置的步骤，提供文本模式但标记评分差异。
- 数字人提问后，允许用户点击“再说一遍”“换一种说法”。
- 报告中的每个低分点可展开查看原始转写、评分锚点和练习入口。
- 支持完全删除简历、录音、转写和账户的自助入口。

## 5. 无障碍与包容性

- 提供字幕、文字模式、音量控制、语速控制和高对比度选项。
- 避免仅用颜色表达错误、风险或完成状态。
- 面向口语表达障碍、网络不稳定或不愿录音用户，提供明确的降级体验与评分说明。
