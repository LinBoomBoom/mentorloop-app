# MentorLoop AI 面试产品：预算、合规与上线清单

生成日期：2026-09-19。币种：人民币。适用前提：从零成立中国大陆主体；小程序 + Android/iOS；自研 2.5D 数字人；首发 Java 后端岗位；不购买第三方数字人 SaaS。

## 1. 预算结论

| 方案         | 范围                                                           | 建议准备现金 |
| ------------ | -------------------------------------------------------------- | -----------: |
| 验证版       | 仅小程序、一个岗位、一个数字人、基础报告                       |     15–25 万 |
| 推荐商业 MVP | 小程序 + App Beta、简历优化、动态追问、专项训练、首 6 个月运行 |    75–105 万 |
| 稳定商业化版 | 多岗位、多角色、多音色、机构版、持续增长投入                   |   130–220 万 |

推荐按 **90 万元** 作为首阶段资金计划：研发 50 万、开办与合规 8 万、设备/题库/测试 5 万、首 6 个月云与 AI 7 万、首批运营获客 10 万、风险准备金 10 万。

## 4. 上线后技术成本

测算基准：每月 1,000 场、每场约 20 分钟面试。

| 项目                                    |     每月估算 |
| --------------------------------------- | -----------: |
| 云服务器、数据库、缓存、存储、CDN、日志 | 0.15–0.45 万 |
| 流式 ASR、TTS、模型调用                 | 0.15–0.45 万 |
| 短信、邮件、客服、监控与安全            |  0.05–0.2 万 |
| 维护、内容运营、客服与小版本迭代        |     1.5–4 万 |
| 合计                                    |  1.85–5.1 万 |

云和模型应先使用按量服务，并设置预算上限、限流、单用户配额和异常告警。自建 TTS/ASR 或 GPU 推理会降低部分调用单价，但会提高模型工程、GPU、运维和容灾成本，不建议在首年为节约调用费而仓促自建。

## 5. 上线合规清单

- [ ] 已设立适当主体，经营范围与实际业务匹配。
- [ ] 已申请域名、完成 ICP 备案；上线后按要求完成公安联网备案。
- [ ] 已完成 App 备案，并准备小程序和应用市场所需主体资料。
- [ ] 已发布隐私政策、用户协议、未成年人规则、投诉举报入口和数据删除入口。
- [ ] 已完成第三方 SDK 清单、个人信息收集清单和权限最小化配置。
- [ ] 已建立简历、录音、转写、声纹、报告的存储期限和删除机制。
- [ ] 已评估生成式 AI、深度合成、算法推荐及内容安全相关义务；必要时办理安全评估或备案。
- [ ] 已完成渗透测试、接口鉴权、限流、备份恢复和应急预案。
- [ ] 已完成微信支付、Apple/Android 支付及税务处理方案。

## 6. 成本控制原则

1. MVP 先做小程序，App 与小程序共用代码库但分批上架。
2. 数字人先做一个可复用角色和动作库，避免首发大量角色美术投入。
3. 先采用云端 ASR/TTS/LLM，基于真实面试量计算单位经济模型后再考虑自建。
4. 以“每场面试的综合毛利”控制模型与语音成本，不以单个 API 单价做孤立决策。
5. 预留至少 10%–15% 风险资金，用于合规整改、模型变化、应用审核和真机兼容。
