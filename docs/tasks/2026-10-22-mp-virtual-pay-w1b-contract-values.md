# 任务卡：W1b 虚拟支付契约冻结（取值）

- 日期：2026-10-22
- 关联：里程碑 M2「支付与会员」/ 父卡 [2026-10-21-mp-virtual-payment-feasibility.md](./2026-10-21-mp-virtual-payment-feasibility.md) §12 W1b

## 1. 目标

把 W0 拿到的真实 `OfferID` / `AppKey` / 5 个 `productId` 写入已冻结的结构，消除硬编码漂移。

## 2. 范围

- 做：
  - 在冻结单追加取值章节与 `skuId → productId` 映射；
  - 记录已知非敏感取值：AppID `wx83b5d63ecd739421`、OfferID `1450672438`；
  - 确认 `skus.ts` 的 `wxProductId` 字段命名；
  - 登记 `AppKey` 存放位置（云端变量 `MP_APP_KEY`，不落明文）。
- 不做：
  - 不改契约结构；
  - 不改价格与权益规则；
  - 不在仓库写任何密钥明文；
  - 不发起真实支付。

## 3. 依赖

- 前置：W0（真实取值）、W1a（结构已冻结）
- 外部环境：虚拟支付后台只读权限
- 契约：是（同一冻结单追加）

## 4. 验收标准

- [x] 冻结单含 5 条 `skuId → productId` 映射，与 W0 后台截图一致
- [x] `OfferID` 与 `AppKey` 仅登记键名与云端存放位置，明文不落仓库
- [x] `skus.ts` 的 `wxProductId` 字段命名与冻结单一致
- [x] 与 W0 截图逐项比对记录入验收记录

## 5. 风险与对策

| 风险                            | 等级 | 对策                                                      |
| ------------------------------- | ---- | --------------------------------------------------------- |
| 后台取值与 `skus.ts` 价格不一致 | 高   | 以后台为准，回写 `skus.ts` 前先由 PO 确认，不得客户端传价 |
| 与 W1a 并发编辑同一冻结单       | 中   | W1b 必须等 W1a 双签完成后再追加，只动取值章节             |
