# 任务卡：iPhone 风格全局改版 + 面试房间对话化（设计已评审）

- 日期：2026-10-23
- 关联：设计评审稿 [2026-10-23-premium-redesign-proposal.md](../design/2026-10-23-premium-redesign-proposal.md)；效果图 [全局改版](../design/2026-10-23-premium-system-mockup.html)、[面试房间](../design/2026-10-23-interview-chat-room-mockup.html)
- 决策：用户 2026-10-23 确认按当前设计开发（3 Tab、token 值调整、浅色聊天、语音默认开启可静音）

## 1. 目标

把现有偏工程化的深色/蓝色界面统一为 iOS 系统分组式视觉，并将面试房间从「题目卡 + 语音面板」改为对话式聊天窗口，使产品达到可面向用户的高级观感，同时用 3 Tab 把「面试 → 报告 → 训练」串成闭环。

## 2. 范围

- 做：
  - P0：token 值三载体同步（`main.css` / `styles/theme.uts` / `MASTER.md §A1`）；tabBar 4 → 3（练习 / 成长 / 我的）
  - P1：首页、我的、会员页按新视觉重做；`ml-card` / `ml-button` 等基础组件的圆角与描边随 token 生效
  - P2：面试房间对话化（AI 气泡流式出字 + 语音同步、按住说话、文字输入、录音面板、转写确认、结束二次确认）
  - P3：成长页承载「报告 / 训练」双段，专项训练不再占独立 Tab；训练入口改为页面跳转
  - P4：全量视觉回归与 G2 门禁
- 不做：
  - 不改面试引擎、评分规则、题库与报告数据结构
  - 不新增服务端接口，不新增契约
  - 不改支付与手机号绑定规则（沿用已上线实现）
  - 不引入图表库、毛玻璃依赖或内联 SVG 图标

## 3. 依赖

- 前置：设计评审通过（2026-10-23）；手机号绑定已完成
- 外部环境：无新增；真机走查需体验版
- 契约：不改 `types/` 或 `api/` 字段，无需契约冻结

## 4. 验收标准

- [ ] `main.css` / `theme.uts` / `MASTER.md §A1` 的 17 项 token 值一致，`check-design-tokens.mjs` 全绿
- [ ] Tab 数量为 3（练习 / 成长 / 我的），训练页不再出现在 tabBar；所有原 `switchTab` 到训练页的入口改为 `navigateTo`
- [ ] 首页、我的、会员页在 375×812 下无内容遮挡，主 CTA 与 tabBar 不重叠
- [ ] 面试房间以消息流呈现：AI 题目气泡逐字上屏、播报状态可见、用户回答成气泡、转写结果可编辑确认、未确认不推进
- [ ] 房间保留：无实时分数、结束二次确认、异常退出保留已答、AI「系统生成」标识
- [ ] 语音不可用 / 麦克风拒绝时自动降级文字模式并有明确出口
- [ ] 成长页可在「报告 / 训练」间切换；报告与训练入口均可到达
- [ ] `pnpm lint` / `typecheck` / `test` / `check-uvue-css` / `check-design-tokens` / `build:mp-weixin` 全绿
- [ ] 375×812 与 320×568 两个尺寸目视走查无溢出、无遮挡

## 5. 风险与对策

| 风险                                  | 等级 | 对策                                                         |
| ------------------------------------- | ---- | ------------------------------------------------------------ |
| token 值全局变更导致全站视觉漂移      | 高   | 三载体一次改齐；逐页目视走查；组件圆角统一由 token 派生      |
| 面试房间改造破坏语音/ASR/TTS 主链路   | 高   | 只重构模板与消息状态，复用现有 ask / record / answer 函数    |
| tabBar 改 3 项后残留 `switchTab` 调用 | 中   | 全局搜索并改为 `navigateTo`；训练页注册为非 tab 页           |
| 成长页合并后报告分段逻辑回归          | 中   | 保留现有 `report-segment` 意图；新增分段只做入口层，不改报告 |
| uvue 不支持毛玻璃 / 内联 SVG          | 中   | Tabbar 用半透明白底 + 描边模拟；图标用字体图标 / PNG         |
| 小屏 320×568 内容挤压                 | 中   | 聊天区独立滚动、输入条固定；首页卡片减少堆叠                 |
