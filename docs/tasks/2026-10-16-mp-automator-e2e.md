# 任务卡：小程序自动化 E2E 接入（mp-e2e）

- 日期：2026-10-16
- 关联：里程碑 M1；SOP-01 角色体系；链型 **标准链**（任务卡 G1 → 实现 → G2 → G3）
- 承接：`docs/tasks/2026-10-14-ia-consolidation.accept.md`（IA-1 走查清单）与 `docs/tasks/2026-10-14-engineering-workbench-redesign.accept.md`（ui-1 走查清单）中**无法靠肉眼判定**的导航类场景；`docs/closure-development-plan.md` §8 登记的「客户端闭环 E2E 缺失」

## 1. 目标

把「真机走查」中可判定的导航类场景从人工肉眼改为**可重复执行的自动断言**，使 G3 验收结论有机器证据（截图 + 断言结果），而不是一次性的人工勾选。

## 2. 范围

- 做：
  - 接入微信官方自动化 SDK `miniprogram-automator`（devDependency）。
  - 新增 `e2e/mp/` 运行器与场景集，`pnpm test:mp` 一键执行；产出结论 + 截图落盘。
  - 覆盖 IA-1 的导航组场景：A1（4 tab 可切换）、B1–B5（首页五个入口去向）、C1–C3（报告页页内分段）、D2/D3（跨 tab 分段深链与一次性语义）。
  - 为上述场景所需元素补稳定选择器（`.uvue` 内的 `id`），避免依赖 Tailwind 原子类名。
- 不做：
  - 不改 `types/`、`api/`、`server/`、`engine/`（**不触发契约冻结**）。
  - 不做 ui-1 的视觉类断言（字体/对比度/圆角无法用 API 断言，仍靠截图走查；截图能力已在 2026-10-16 验证可用）。
  - 不覆盖需要登录态/真实后端的场景（E1 死链全量遍历、E2 退出登录落首页、报告页有数据态）——登记为后续批次。
  - 不引入 Playwright（`test:e2e` 现为无配置的空壳，本卡不动它）。
  - 不改 CI（本卡只保证本机可跑；进 CI 需专用 runner 带 DevTools，另立卡）。

## 3. 依赖

- 前置：DevTools 已导入 `dist/build/mp-weixin` 并完成一次 `pnpm build:mp-weixin`。
- 外部环境：
  - 微信开发者工具 **CLI**：`D:\Tencent\微信web开发者工具\cli.bat`（已确认存在）。
  - **服务端口须开启**：DevTools → 设置 → 安全设置 → 服务端口「开启」（当前未监听 9420，**需人工开启**）。
  - Node ≥ 22（本机 v22.22.2）。
- 契约：无（`types/`、`api/` 零改动）。

## 4. 验收标准

- [ ] `pnpm test:mp` 在服务端口开启后可一条命令跑完并输出结论摘要（通过/失败数 + 失败场景号）。
- [ ] 覆盖场景至少：IA-1 A1、B1、B2、B3、B4、B5、C1、C2、D2、D3（每条有断言，非仅截图）。
- [ ] D2/D3 断言「数据条 → 结果 tab 且落在成长趋势」与「意图一次性、不重放」（本卡核心回归对象）。
- [ ] 失败时产出截图落盘 `e2e/mp/__screenshots__/`，并在控制台输出场景号 + 期望/实际。
- [ ] 新增选择器不改变任何页面视觉与交互（仅新增 `id` 属性）。
- [ ] `pnpm lint` / `pnpm test` / `pnpm build:mp-weixin` 全绿。

## 5. 风险与对策

| 风险                                           | 等级 | 对策                                                                         |
| ---------------------------------------------- | ---- | ---------------------------------------------------------------------------- |
| 服务端口未开导致连不上，脚本报错信息不友好     | 中   | 运行器先探测端口，未开则输出明确的「请开启服务端口」指引并以非 0 退出        |
| `dist/` 产物陈旧，跑的是旧代码                 | 中   | 运行器启动前强制 `pnpm build:mp-weixin`（可用 `--no-build` 跳过）            |
| uvue 编译后 class 名不可靠，选择器易碎         | 中   | 关键元素补 `id` 选择器；断言优先用页面路径与元素存在性，不依赖样式类         |
| 「成长趋势」分段无数据时元素不存在，断言假失败 | 中   | 断言改为「分段激活态 / 面板容器存在」，并允许空态文案出现                    |
| 自动化实例与用户手动开的 DevTools 冲突         | 低   | 运行器默认 `automator.launch()` 独立实例；用完 `close()`；失败兜底不残留进程 |
