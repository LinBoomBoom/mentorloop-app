## 3. 今日补充的系统规则（用户定版）

1. **UI 设计只出 HTML**：不再导出 PNG/JPG 设计图，评审直接打开 HTML。
2. **原生 tabBar 三等分**：不浮 FAB、不挤占 tab；主行动放回页面内容。中央主行动只能走 uni-ui x `uni-tab-bar` 的架构级改造，且需另立卡。
3. **留白是设计**：不得用装饰性图表 / 趋势卡 / 假入口填空。
4. **只设计系统已支持的功能**：超前设计必须标注「超前 · 未实现」。
5. **玻璃有平台边界**：App 真 blur，MP 模拟，原生 tabBar 一律不支持。
6. **设计稿必须画平台 chrome**：胶囊、状态栏、安全区不能只写在注释里。

以上已写入项目 memory 与 user_profile；第 1、2、5、6 条同时写入两个设计 skill 并同步 SOP 索引。
