# 任务卡：W0 虚拟支付凭据与商品准备

- 日期：2026-10-22
- 关联：里程碑 M2「支付与会员」/ 父卡 [2026-10-21-mp-virtual-payment-feasibility.md](./2026-10-21-mp-virtual-payment-feasibility.md) §12 W0
- 性质：**外部准备卡（后台配置与取证，不改代码）**

## 1. 目标

在 W1a / W2 开工前，把虚拟支付所需的后台凭据、5 个道具、iOS 简称、消息推送 URL 与合规确认全部就绪并可回读，消除签名与道具层面的必然失败。

## 2. 范围

- 做：
  - 补齐云端 `WX_APPID` / `WX_SECRET` 并回读（与 ASR 卡共用，先对齐）；
  - 录入虚拟支付后台 `OfferID`、现网 `AppKey`；
  - 按 `server/src/data/skus.ts:14-56` 发布 5 个道具，价格逐分一致；
  - 配置 iOS 小程序简称；
  - 确定消息推送接收 URL 并完成平台测试推送；
  - LC 复核结算账户、退款政策与 iOS 45–60 天现金流。
- 不做：
  - 不改任何客户端 / 服务端代码；
  - 不改数据库结构；
  - 不发起真实支付；
  - 不调整 SKU 价格与权益规则。

## 3. 依赖

- 前置：无（可与 W1a 并行）
- 外部环境：微信公众平台管理员权限、虚拟支付后台权限、云托管控制台权限
- 契约：否（本卡不改 `types/` 或 `api/`）

## 4. 验收标准

- [ ] 云端 EnvParams 回读含 `WX_APPID` / `WX_SECRET`，脱敏截图入验收记录
- [ ] 虚拟支付后台 5 个道具已发布：`member_monthly` / `member_yearly` / `single_pack_3` / `single_pack_10` / `resume_pack_3`
- [ ] 5 个道具价格与 `skus.ts` 逐分一致（3900 / 22800 / 2900 / 7900 / 2900）
- [ ] iOS 小程序简称已配置
- [ ] 消息推送 URL 已确定，平台测试推送返回成功
- [ ] 道具发布后等待 ≥ 10 分钟生效，记录发布时间与联调时间
- [ ] LC 出具结算 / 退款 / 现金流确认单

## 5. 风险与对策

| 风险                             | 等级 | 对策                                                        |
| -------------------------------- | ---- | ----------------------------------------------------------- |
| 道具被按教育类复核               | 中   | 按实际工具功能如实提交；驳回理由指向类目则触发父卡 §13 回退 |
| `WX_SECRET` 获取/重置影响 ASR 卡 | 高   | 与 ASR 卡共用，先对齐再操作；回读后通知 ASR 卡主责          |
| 道具发布未生效（-15014）         | 低   | 发布后 ≥ 10 分钟再联调，验收记录登记时间                    |
| 消息推送 URL 不可用              | 中   | 首选云托管 HTTPS；失败按父卡 §13 回退云函数转发             |
