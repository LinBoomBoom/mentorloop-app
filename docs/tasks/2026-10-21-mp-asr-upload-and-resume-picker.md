# 任务卡：录音作答上行（云存储中转）+ 简历页选文件体验修正

- 日期：2026-10-21
- 关联：契约冻结 `docs/contracts/2026-10-21-asr-cloud-upload.freeze.md`；承接 `docs/tasks/2026-10-19-mp-voice-tts-outbound.md`（TTS 下行已交付）
- 性质：**实施卡**（ASR 上行批次 + 简历页 UX 修正）

## 1. 目标

1. 小程序端**录音作答可用**：录完音后服务端返回真实转写文本，不再恒提示「没有听清你的回答」。
2. 简历页「选择文件」不再让人误以为在「分享给好友」：给出明确来源说明，并增加「从相册选图片」入口。

## 2. 范围

- 做：新增 `POST /interview/asr-cloud`；`wx-storage.ts` 增 fileID → 下载链接；客户端 `uploadAsrCloud` + 房间页 MP 分支接线；简历页来源引导 + 相册入口。
- 不做：wechatSI 插件（个人主体不可用）；ICP 备案/自有域名；App 端 ASR 既有路径改动；简历解析算法。

## 3. 依赖

- 云端已有 `WX_APPID` / `WX_SECRET`（15 键中的 2 项，TTS 批次已注入）。
- 需注入 `ASR_PROVIDER=wx`（当前未设，默认 stub）。
- 官方接口：`POST /cgi-bin/token`、`POST /tcb/batchdownloadfile`、`POST /cgi-bin/media/voice/addvoicetorecofortext`（≤1MB、≤60s、mp3）。

## 4. 验收标准

- [ ] `POST /interview/asr-cloud` 出入参与冻结记录逐字一致
- [ ] 云端 `ASR_PROVIDER=wx` 下，真机录一段话 → 返回非空 `text`，字幕上屏并进入作答链
- [ ] 转写完成后云存储**无残留录音对象**（`tcb storage list` 无 `asr/` 前缀）
- [ ] 微信接口不可用（缺凭据/超限）→ `text=''` 降级，**不伪造、不阻塞、不弹窗**
- [ ] `POST /interview/asr`（multipart）行为零变化
- [ ] 简历页：按钮区明确标注文件来源；相册入口可选图片并能走通解析

## 5. 风险与对策

| 风险                                            | 等级 | 对策                                                                                 |
| ----------------------------------------------- | ---- | ------------------------------------------------------------------------------------ |
| 录音超 1MB / 超 60s（微信硬限）                 | 高   | 客户端限制单次录音 ≤60s；服务端按 1MB 校验并降级提示改用文字                         |
| `addvoicetorecofortext` 为旧接口，可能限流/下线 | 中   | 失败即诚实降级；若确认下线，改腾讯云 ASR（另一张卡）                                 |
| fileID 可由客户端伪造（越权读取他人文件）       | 中   | 仅接受 `cloud://` 前缀；服务端只取临时链接不列目录；建议后续加 `asr/<uid>/` 路径校验 |
| 删除录音失败导致残留                            | 低   | 客户端 best-effort 删除 + 服务端不落盘（临时文件 finally unlink）                    |

## 9. 开工前质询

| #   | 质询                              | 结论                                                                                                         |
| --- | --------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 1   | 为什么不走 multipart `upload()`？ | 需公网 `BASE_URL`；云托管默认域名不可配到小程序后台（官方明文），个人主体也无备案域名 → 必须走云存储私有链路 |
| 2   | 服务端怎么拿音频？                | 官方 `POST /tcb/batchdownloadfile?access_token=`，返回 `download_url`（已核实签名与出参）                    |
| 3   | 隐私如何保证？                    | 录音仅中转：客户端转写后立刻 `wx.cloud.deleteFile`；服务端只写临时文件并 `finally unlink`                    |
| 4   | 简历页为何不能像网页那样选文件？  | 小程序无系统文件浏览器 API；`wx.chooseMessageFile` 官方语义即「从客户端会话选择文件」                        |

## 11. 遗留（需另开卡）

| #   | 事项                   | 说明                                                                                                                                                                                                    |
| --- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **TTS 音频会长期堆积** | 每念一题就在云存储留一个 mp3（本次测试残留 12 个）。契约只说了「不做缓存」，没说「用完即删」。建议给 `tts/` 前缀配置生命周期规则（如 7 天自动删除），或客户端播完即删（需权衡重复念题）。当前不影响功能 |
| 2   | 微信 ASR 为旧接口      | `addvoicetorecofortext` 属「智能接口/AI 开放接口」，官方仍标注小程序可调用，但文档在「服务号」分类下；若后续限流或下线，改腾讯云 ASR（另一张卡）                                                        |
| 3   | 单次录音 ≤60s          | 微信 ASR 硬限（1MB / 60s）；当前未在客户端做时长上限，超长会降级为空文本后提示重录                                                                                                                      |
