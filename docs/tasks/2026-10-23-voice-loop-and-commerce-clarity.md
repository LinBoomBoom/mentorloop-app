# 任务卡：语音闭环可见性 + 套餐权益动态化 + 歧义收口

- 日期：2026-10-23
- 来源：用户体验版真机走查反馈（4 项）
- 链型：标准链（G1 任务卡 → 实现 → G2 → G3）；不改 `types/` 与 `api/` 入出参

## 1. 目标

让语音作答「说得清、看得见、改得动」，让会员/加量包权益随套餐真实变化，并把简历历史回放与登录门控的歧义一次收口。

## 2. 范围

- 做：
  1. **语音闭环（P0）**
     - 面试房间：录音转写后**不自动跳题**，先展示识别文本（可编辑）→「确认提交 / 重新录制」；字幕常驻显示实时与最终识别文本。
     - 训练房间：同上，确认后展示即时反馈并手动「下一题」，不再 1.2s 自动推进。
     - TTS：合成/播放失败不再静默；题面下方明示「面试官正在播报… / 语音播报暂不可用，请阅读题面」。
  2. **套餐权益动态化**：权益列表按当前选中 SKU 渲染（月卡/年卡/单次包/简历包各不相同）；会员套餐与加量包分区，加量包明示「无需开通会员」。
  3. **歧义收口**：简历解析历史点击后进入独立详情页回放，不再就地覆盖当前解析/优化页。
  4. **登录口径**：小程序端 openid 静默登录即可进入面试，取消「必须手机号身份」门控；登录层仅作静默登录失败时的兜底。
- 不做：
  - 手机号在购买时绑定：服务端无绑定端点，属契约变更，另立卡（需契约冻结 + `POST /me/phone`）。
  - 真实 TTS/ASR 通道改造、云托管环境变量变更。
  - 报告/评分算法、内容库、`types/` 与 `api/` 入出参。
  - 整站视觉重做。

## 3. 依赖

- 前置：TTS 契约 `2026-10-19-tts-outbound.freeze.md`、`2026-10-21-tts-ack-and-file-ownership.freeze.md`；简历详情 `GET /resume/:id` 已存在。

- 契约：零变更（客户端仅消费既有字段）。

## 4. 验收标准

- [x] 面试房间停止录音后，页面显示识别文本；未点「确认提交」不会进入下一题。
- [x] 识别文本可编辑；「重新录制」丢弃本次识别并回到录音态。
- [x] 录音过程中实时识别文本持续显示在字幕区，不被状态文案覆盖。
- [x] TTS 合成/播放失败时题面下方出现「语音播报暂不可用」；播放中显示「正在播报」。
- [x] 训练房间停止录音后显示识别文本与确认入口；确认后显示即时反馈并可手动进入下一题。
- [x] 会员页切换套餐时权益列表内容随之改变；会员套餐与加量包分区展示，加量包有「无需开通会员」说明。
- [x] 简历解析历史点击进入 `pages/resume/detail`，当前页解析/建议不被覆盖。
- [x] 小程序端静默登录成功即可进入面试，不再要求手机号；未登录时静默登录失败才弹登录层。
- [x] `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build:mp-weixin` 退出码 0。
- [x] 真机复验：面试官念题可出声（2026-10-23 复测通过；云端密钥更新 + 本地下载播放，见 gate §5）。

## 5. 风险与对策

| 风险                           | 等级 | 对策                                                               |
| ------------------------------ | ---- | ------------------------------------------------------------------ |
| 增加确认步骤拉长单题耗时       | 中   | 确认面板一步到位（文本可改 + 两个按钮），不引入二次弹窗            |
| 用户误以为「确认」即提交服务端 | 低   | 按钮文案「确认提交」，提交后字幕回显「已记录你的回答」             |
| TTS 明示不可用被当成功能缺失   | 中   | 文案给替代路径（阅读题面 / 再说一遍），不弹错误                    |
| 去掉手机号门控影响账号归属     | 中   | openid 即账号主体；手机号绑定购买前补，另立卡                      |
| 权益分档被质疑「虚假承诺」     | 中   | 只写代码已实现能力；单次包明确「不含专项训练不限次与简历月度额度」 |
