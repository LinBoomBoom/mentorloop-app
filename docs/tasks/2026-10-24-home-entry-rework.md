# 任务卡：首页入口重排（训练入口常驻 + 首屏不滚动）

> 2026-10-24 视觉复审：首版实现被用户否决（「不好看」）；6 概念与 A/B 细化又被判定「太刻意」。已实测调研 Linear / Raycast / Vercel / Nothing / Things 3 / Google Interview Warmup，提炼 8 条「酷而不刻意」原则，删除 sci-fi 道具，收敛为 [2 个方向的高保真细稿](../design/2026-10-24-home-hifi-quiet-paper.html)：A · Quiet Stage / B · Paper Signal。2026-10-25 用户追加 4 层大厂质感框架，已出 [Glass Studio 可交互原型](../design/2026-10-25-home-glass-studio-prototype.html)（CSS 材质 + 动效 + Three.js + 组件系统），但被判定「排版不适配移动端 + Three.js 不适配小程序」——**Glass Studio 仅作 Web 材质研究，不再作为 App/MP 设计目标**。
>
> **当前设计目标（2026-10-25 第二轮修订）**：用户提供 3 张 NOVA One 参考图，定调「Apple 风格 + 轻科技感 + 轻炫酷感 + 实干/主次/边界/空间感」。第二轮反馈后已按 8 条意见重做 [NOVA 移动首页](../design/2026-10-25-home-nova-mobile.html)（App / MP / 360 三帧，**只出 HTML，不导出图片**）+ uvue 落地规格 [home-nova-mobile-spec.md](../design/2026-10-25-home-nova-mobile-spec.md)。核心结构：玻璃顶栏（MP 预留胶囊 100px）→ 问候 → 三卡仪表盘（渐变主卡 + 声波 + 卡内白色 CTA；上次评级 + 本周节奏）→ 今日任务卡 → 2 列快捷入口 → 纯留白 → 原生 tabBar 三等分。**已删除：中央 FAB、近 7 天柱状图、通知铃铛**。NOVA 待评审，评审通过后才允许改 `pages/index/index.uvue`。

- 日期：2026-10-24
- 关联：P1 体验优化；来源 2026-10-24 用户真机反馈（首页缺训练入口、简历入口需滚动才可见）

## 1. 目标

让首页首屏直接给出「模拟面试 / 专项训练 / 简历优化 / 今日任务 / 成长」五个下一步，训练入口不再依赖是否出过报告，并在默认字号下做到不滚动即可看全，提升训练与简历两条链路的可达性。

## 2. 范围

- 做：
  - 首页信息架构重排为五层：问候头 → 模拟面试主卡 → 训练/简历两列入口 → 今日任务 → 成长条。
  - 新增常驻「专项训练」卡（自选方向 / 细分 / 难度 · 5 题一组），无报告用户也可一键进入 `/pages/training/training`。
  - 「今日做题」取消 `hasReport` 限制，双态：无报告 = 「先做 5 题摸底 · 生成训练画像」；有报告 = 「今日做题 · N 个待完成」。
  - 合并「今日闭环」三张统计卡 + 最近报告卡为一条紧凑成长条（保留累计场次、最近等级、最近报告入口、成长入口）。
  - 小屏 compact 模式：按 `uni.getWindowInfo().windowHeight` 隐藏次要说明行，默认字号下不滚动；大字号允许滚动兜底，不得裁切。
  - 保留 E2E 锚点语义：`#home-profile-card` / `#home-resume` / `#home-recent-report` / `#stat-total` / `#stat-avg` / `#stat-todo`。
- 不做：
  - 不新增 Tab、不改 tabBar 文案 / 图标 / 顺序。
  - 不改训练页、成长页内部结构与额度逻辑。
  - 不做个性化推荐、智能排序。
  - 不改简历页与简历链路（见另卡 [2026-10-24-resume-free-value-funnel.md](./2026-10-24-resume-free-value-funnel.md)）。
  - 不做首页动画 / 插画等装饰性内容。

## 3. 依赖

- 前置：训练页支持无报告自选（已查证：`pages/training/training.uvue` 方向 / 细分 / 难度自选，不读报告；`pages/report/report.uvue` 的「查看全部做题」直达同一页）。
- 外部环境：真机走查需 360×640 Android、375×667 iPhone SE、390×844 三档；无新增密钥。
- 契约：不改 `types/`、`api/`、服务端出参 → 无需契约冻结。

## 4. 验收标准

- [ ] 360×640 Android 与 375×667 iPhone SE 默认字号：模拟面试主卡、专项训练卡、简历优化卡、今日任务、成长条全部首屏可见，页面不出现纵向滚动。
- [ ] 匿名 / 已登录、有报告 / 无报告 四种状态均不滚动；简历卡无需滚动即可见。
- [ ] 无报告用户点击「专项训练」1 次到达 `/pages/training/training`；今日任务显示「先做 5 题摸底 · 生成训练画像」。
- [ ] 训练卡与简历卡并排时，360px 宽度下标题 / 副标题不换行不截断（副标题单行 `truncate`）。
- [ ] 系统大字号下允许滚动，但卡片不重叠、文字不裁切。

- [x] 6 个 E2E 锚点语义不变，`IA1-*` 场景失败 0（B2/B3/B5 因环境无报告数据跳过，见 gate）
- [x] `pnpm lint` / `pnpm typecheck` / `pnpm test` / `pnpm build:mp-weixin` / uvue CSS 守卫 / 设计 token 守卫全绿
- [ ] 真机走查记录（三档机型截图）落 gate 文档。

## 5. 风险与对策

| 风险                    | 等级 | 对策                                                                                 |
| ----------------------- | ---- | ------------------------------------------------------------------------------------ |
| 小屏仍溢出              | 高   | 高度预算 ≤ 506px（见 §10）；windowHeight < 620 进入 compact 隐藏说明行；三档真机验收 |
| 合并统计卡导致信息丢失  | 中   | 成长条保留累计场次、最近等级、最近报告入口与成长入口；E2E 锚点语义不变               |
| 两列卡片文字挤压        | 中   | 标题 14px 单行、副标题 12px 单行 truncate；图标 28px；不放大段说明                   |
| 用户找不到「查看成长」  | 低   | 成长条整行可点，文案改为「成长报告」；点击落成长页报告分段                           |
| 与微信胶囊 / 状态栏冲突 | 中   | 保留 `rightPad` / `topPad` 逻辑；两列卡片上方不得放右上角操作                        |
| E2E 锚点迁移导致误报    | 中   | 先保留 id 在等价新节点，再跑 IA1-B1/B2/B3/B4/B5                                      |
| 大字号裁切              | 中   | 不用固定高度裁剪，允许 scroll-view 兜底滚动                                          |

## 10. 布局草案与高度预算

```
[日期 · 问候]                              [头像]
┌────────────────────────────────────────────────┐
│ 模拟面试（唯一主 CTA）                          │
└────────────────────────────────────────────────┘
┌──────────────────┐  ┌──────────────────┐
│ 专项训练          │  │ 简历优化          │
│ 自选方向 · 5 题一组│  │ AI 解析 · 逐条批注 │
└──────────────────┘  └──────────────────┘
┌────────────────────────────────────────────────┐
│ 今日任务（摸底 / 今日做题）        [去做题]     │
└────────────────────────────────────────────────┘
已练 12 场 · 最近 A · 成长报告 › （含最近报告入口）
```

| 区块            | 默认态高度（px，估算） |
| --------------- | ---------------------- |
| 顶部问候头      | 50                     |
| 模拟面试主卡    | 176                    |
| 训练 / 简历两列 | 96                     |
| 今日任务        | 74                     |
| 成长条          | 40                     |
| 间隔与内边距    | 70                     |
| 合计            | ≈ 506（不含状态栏）    |

- 可用高度参考：iPhone SE 667 − 50（tabBar）− 28（状态栏 + 顶部间距）≈ 589；Android 640 − 56 − 24 ≈ 560。
- `compact` 阈值：`uni.getWindowInfo().windowHeight < 620` 时隐藏主卡描述尾行与两列卡副标题，预算降至 ≈ 450px。
- 两列卡统一使用 `ml-card :padded="false"` + 内部 `p-3`，禁止手搓卡片（设计 token 检查 G）。
- 字号仅使用 token 白名单：14 / 12；触摸热区 ≥ 44px。
