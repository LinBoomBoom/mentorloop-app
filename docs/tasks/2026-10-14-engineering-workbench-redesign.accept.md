## 3. 真机走查场景清单（Given / When / Then）

> 执行方式：微信开发者工具 → 编译预览；逐条勾选，失败项记录「场景号 + 现象 + 截图」。

### A. 首页（U1 / U2 / U6）

- [ ] **A1** Given 首页首屏，Then 无 blur 光晕层、无轮播文案气泡；`ml-voice-visual` 直径 ≤88 且位于卡内。
- [ ] **A2** Given 首页，Then 存在「本次模拟面试」参数卡（岗位 / 经验 / 能力域）且首屏可读。
- [ ] **A3** Given 首页数据条与等级数字，Then 为等宽字体（不是比例字体）。
- [ ] **A4** Given 首页深色卡片正文，Then 正文为 white 系（对比度足够），`mist` 仅出现在辅助行。

### B. 面试房间（U3）

- [ ] **B1** Given 面试房间，Then 无 208px 光环舞台、无 blur 光晕。
- [ ] **B2** Given 面试房间，Then 当前题目位于页面中部题目卡内，题面字号 ≥18px，题号为等宽。
- [ ] **B3** Given 面试房间，Then AI 标识为「AI 面试官 · 系统生成」，且**页面任何位置都不显示实时评分**。
- [ ] **B4** Given 面试房间，Then 语音状态可视化仍在（ring 96 辅助位），「再说一遍 / 换一种说法」可正常触发。

### C. 报告（U4 / U5）

- [ ] **C1** Given 报告页，Then 每个能力维度**同时**显示等级与置信度档位。
- [ ] **C2** Given 存在低置信度（<0.5）维度，Then 该维度显示「证据不足，仅供参考」。
- [ ] **C3** Given 报告能力维度卡，When 点击展开，Then 证据区呈「你的回答摘录 ↔ 待补证据 / 参考答法」对照结构。
- [ ] **C4** Given 报告总体判断卡，Then 可见「综合置信度」。
