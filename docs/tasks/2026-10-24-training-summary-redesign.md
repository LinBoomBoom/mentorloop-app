# 任务卡：训练小结页重设计

- 日期：2026-10-24
- 关联：训练做题模式（`2026-10-23-practice-subtrack-mode`）；设计稿 [2026-10-24-training-summary-redesign.html](../design/2026-10-24-training-summary-redesign.html)

## 1. 目标

把训练小结从「数据卡片 + 按钮列表」改成「做题后的价值交付 + 下一动作引导」：先回答这组练得怎样，再回答接下来做什么。

## 2. 范围

- 做：
  - 本组结果结论 + 会/模糊/不会分段条与计数；
  - 动态主行动：有待巩固题先复习；全对则续组或换一组；
  - 待巩固题列表（模糊 + 不会）与「明天复习」预期；
  - 全对空态；
  - 去掉「本机已记录掌握度」等技术文案。
- 不做：
  - 不改训练出题、SRS 算法、接口契约；
  - 不引入图表库或实时评分；
  - 不改做题房间的答题流程。

## 3. 依赖

- 前置：现有 `results` / `sessionWrong` / `subtrackLabel` / `difficultyText` 数据；设计稿评审通过（2026-10-24）。
- 外部环境：开发者工具 375×812 + 320×568 走查。
- 契约：不改 `types/` / `api/`。

## 4. 验收标准

- [x] 小结首屏展示「这组答对 X 题」或「这组全部答对」，并给出会/模糊/不会计数与分段条。
- [x] 有待巩固题时主按钮为「复习待巩固题」，次按钮为「再来 5 题」。
- [x] 全对时主按钮切换为「再来 5 题」，次按钮为「换一组」，并显示无待巩固空态。
- [x] 待巩固列表包含模糊与不会题，附「明天复习」标签；不再使用「Q1」工位编号。
- [x] 技术文案「本机已记录掌握度」移除；最多两个动作按钮。
- [x] G2 全绿；375×812 走查通过；320×568 设计稿通过。

## 5. 风险与对策

| 风险                             | 等级 | 对策                                               |
| -------------------------------- | ---- | -------------------------------------------------- |
| 把「模糊」也称为错题造成语义偏差 | 低   | 文案统一为「待巩固」，说明模糊进 SRS、不会进错题本 |
| 长题面撑高列表                   | 低   | 页面 scroll-view；保留题面完整，不做强制截断       |
| 主行动动态切换让按钮不稳定       | 低   | 只在两种状态间切换，文案与计数一致                 |
| 320 小屏挤压                     | 中   | 设计稿压缩字号/间距；页面可滚动                    |
