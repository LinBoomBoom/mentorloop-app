## 1. 目标

把导航层级对齐业务主线（准备 → 面试 → 复盘 → 训练），使「单场报告 ↔ 跨场成长」归入同一复盘域、简历获得与其业务价值匹配的入口，从而缩短「报告查看 → 训练 → 复面」的路径并强化免费层钩子；同时消除首页与 tab 的功能重叠。

### 9.2 决策前的三方案对比（留痕）

> 决策点可拆为两问：**Q1 成长是否并入「报告」形成复盘域？**（P1）／**Q2 简历是否成为一级 tab？**（P2）
> A = Q1 是 + Q2 否（简历走首页入口）；B = Q1 是 + Q2 是；C = 只做 Q1，tab 名称与数量不动。

| 维度             | **方案 A（推荐）**                           | 方案 B                                               | 方案 C                                       |
| ---------------- | -------------------------------------------- | ---------------------------------------------------- | -------------------------------------------- |
| tabBar           | 首页 / 训练 / **结果** / 我的（4）           | 首页 / **简历** / 训练 / **结果** / 我的（5）        | 首页 / 训练 / 报告 / 我的（4，不变）         |
| Q1 复盘域合并    | ✅                                           | ✅                                                   | ✅                                           |
| Q2 简历一级入口  | ❌（首页显著入口）                           | ✅                                                   | ❌                                           |
| 修复的发现       | P1 / P3 / P4                                 | P1 / P2 / P3 / P4                                    | 仅 P1                                        |
| 需生成新图标     | 否（`trend` 已就绪，可选）                   | **是**（需新增简历图标绘制函数）                     | 否                                           |
| 改动文件数（估） | 4                                            | 5                                                    | 3                                            |
| 主要收益         | 导航 1:1 映射业务环节；报告查看→训练路径缩短 | 简历获最大曝光，对齐免费层钩子                       | 风险最小                                     |
| 主要代价         | 简历仍非一级（首页入口够不够要赌）           | 5 tab 挤压；简历是低频一次性动作，占一级位置性价比低 | 「报告」tab 内含趋势，命名不精确；P2/P4 留债 |
| 与北极星关系     | 报告查看率↑、训练完成率↑                     | 另加免费层转化↑                                      | 报告查看率↑                                  |

**建议：方案 A。** 理由：报告与成长是同一 JTBD（复盘），A 用一次分段切换消掉一次跳转；简历是「一次性准备动作」而非高频动作，占一级 tab 的边际收益低于其挤压成本，用首页显著入口 + 「我的」保留双入口即可覆盖。若 PO 认为简历作为免费钩子需要最大曝光，则选 B（代价是新增 1 个图标与 5 tab 挤压）。
