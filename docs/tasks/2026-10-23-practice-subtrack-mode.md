# 任务卡：训练改为「做题」+ 细分领域 × 难度

- 日期：2026-10-23
- 关联：内容库 600 题（4 方向 × 150，20 个 subtrack，每难度 200 题）；契约冻结 [2026-10-23-practice-subtrack.freeze.md](../contracts/2026-10-23-practice-subtrack.freeze.md)
- 方案：[2026-10-23-practice-mode-proposal.md](../design/2026-10-23-practice-mode-proposal.md)

## 1. 目标

把「专项训练」改造为「做题」，让用户按 **方向 → 细分领域 → 初级/中级/高级** 选题刷题，先想后看解析并自评掌握度，把 600 题内容库从「面试抽题」扩展为日常可用的做题产品。

## 2. 范围

- 做：
  - 服务端：`/training/questions` 支持可选 `subtrack` / `difficulty`（精确难度），候选池 SQL 过滤
  - 客户端：20 个细分领域选择器；难度段（初级/中级/高级）；题量 5/10；做题房间（先想后看解析 + 自评）
  - 本地掌握度与错题本：按细分领域统计已做/会/模糊/不会，不会的题进入错题本并可复习
  - 文案与入口：专项训练 → 做题（首页闭环、成长分段、报告入口、导航标题）
- 不做：
  - 不做选择题/选项化改造（现题库为开放题）
  - 不做服务端 SRS 排程（本期本地记录，Phase 2 再上）
  - 不做完整答案全文入库（本期用既有 `expectedEvidence` 作为「参考解析 · 节选」，Phase 2 补全文）
  - 不做公司真题/面经来源与付费题库

## 3. 依赖

- 前置：内容库 600 题已上线（track/subtrack/difficulty 完整）；G2 改版已完成
- 外部环境：题库接口需登录（静默登录即可）
- 契约：是，已冻结（请求字段扩展，响应不变）

## 4. 验收标准

- [x] 做题页可选 4 个方向、对应细分领域、初级/中级/高级与 5/10 题
- [x] 开始做题后返回的题目 `subAbility` 与所选 subtrack 一致，`difficulty` 与所选难度一致（服务端单测；云端需发布后生效）
- [x] 做题房间可「先想 → 查看解析 → 自评会/模糊/不会 → 下一题」，答完显示小结
- [x] 「不会」的题进入错题本，可从做题页复习；复习时选「会」会移出错题本
- [x] 本地统计（已做/会/模糊/不会/错题数）刷新正确，重启后保留
- [x] 旧调用（不传 subtrack/difficulty）行为不变；面试出题不受影响
- [x] 服务端单测覆盖过滤与精确难度；客户端 lint/typecheck/test/guards/build 全绿（见 [G2 门禁](./2026-10-23-practice-subtrack-mode.gate.md)）

## 5. 风险与对策

| 风险                            | 等级 | 对策                                                              |
| ------------------------------- | ---- | ----------------------------------------------------------------- |
| 细分领域题量不均（op-sec 3 题） | 中   | 页面按实际可用题量提示；不足时返回剩余题并说明                    |
| 难度过滤与经验白名单冲突        | 中   | 传 difficulty 时精确过滤并把选择器经验档置 senior，仅本期生效     |
| 400 字解析不足以自学            | 中   | 明示「参考解析 · 节选」；Phase 2 落全文答案列                     |
| 本地错题本跨设备丢失            | 低   | 本期明示本机保存；Phase 2 随账号同步                              |
| 文案改动范围大导致遗漏          | 中   | 全局搜索「专项训练 / 训练」逐个替换，保留「训练计划」作为报告概念 |
