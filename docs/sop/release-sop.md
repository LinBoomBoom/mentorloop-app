# 发布准入 SOP（G4 发布门）

生成日期：2026-09-24
归属：SOP 系统 L3 执行层 · 生命周期阶段 ④ 交付出口
上游：`quality-gate-sop.md`（G2）；相关：`compliance-sop.md`

---

## 1. 目的与适用

任何对外交付（里程碑版本、小程序提审、App Beta 打包）在发布前必须通过 G4。**G4 不通过，不发布。**

**适用**：M0–M3 里程碑交付、小程序提审、App 打包、正式版发布。
**不适用**：迭代内的日常提交（走 G2 即可）。

---

## 4. 发布执行

1. 按 §2 核验前置条件，填写准入单。
2. 小范围灰度（App 分批 / 小程序灰度），观察北极星指标与崩溃率。
3. 指标异常 → 触发回滚方案。
4. 灰度稳定 → 全量。

---

## 5. 失败动作

- 任一前置条件不通过 → **不发布**，回退到对应阶段修复。
- 合规未完成属**高风险**，不得带病发布（文档 06 §5）。
- 发布必须由 QA/DevOps 给出**书面准入结论**，不得口头放行。
