# 原生插件领域 SOP（utssdk）

---

## 1. 目的与适用

`utssdk/` 用 UTS 插件隔离实时音频、数字人渲染、设备权限等平台差异。本 SOP 规定契约、降级、性能与真机验证纪律。所有 `utssdk/**` 改动适用。

---

## 2. 四个插件职责

| 插件                   | 职责                                     | 现状                                                 |
| ---------------------- | ---------------------------------------- | ---------------------------------------------------- |
| `interviewer-audio`    | 录音、降噪、音频焦点、中断恢复           | 跨端契约 + Android 原生层（`app-android/index.uts`） |
| `interviewer-realtime` | 实时音频通道（WS 传输/重连/离线缓冲）    | 跨端契约                                             |
| `interviewer-avatar`   | 数字人渲染桥（状态机/资产插槽/口型钩子） | 跨端契约；2.5D 原生渲染待美术资产                    |
| `interviewer-device`   | 设备检测（权限/网络/前后台）             | 跨端 UTS 实现                                        |

---

## 3. 契约与降级模式（强制）

每个插件遵循同一结构：

```
<plugin>/
├── index.uts             跨端契约 + 非目标平台降级实现
└── app-android/index.uts Android 原生增强（仅 Android 编译参与）
```

- **UTS 不支持 `interface`**：契约以类的**公开方法**为准，对象类型用 `type`。
- **降级必须显式**：原生未就绪时返回 `false` / 空串 / 空数组，调用方保留既有降级路径（如 `audioPlugin.enhanced === false`）。
- **降级不得伪造**：ASR 不可用时返回空转写，**绝不**编造转写文本（污染证据链）。
- 平台差异用条件编译 `// #ifdef APP-ANDROID` 隔离，保证其他端可编译。

---

## 4. 性能硬约束（文档 04）

- **音频帧/口型不进响应式状态**：振幅摘要按约 12 次/秒回调（`onLevel`）；口型由原生层或 CSS keyframes 消费。
- **单活跃数字人实例**，房间退出即 `release()` / `releaseFocus()`，避免内存增长。
- 资产预加载失败静默，不阻塞面试流程。
- 设备端不做大模型推理。

---

## 5. 真机验证（P3-14）

- 编译/运行只能在 **HBuilderX** 完成（VS Code 仅写代码）。
- 性能与稳定性验证**必须用 release 包**，禁止以 debug 模式或模拟器流畅度作为验收依据。
- 当前仓库未做真机验证，任何 `utssdk` 改动须在真机回归后收口。
- 取证：可用 `computer-use` 操作 HBuilderX + `screenshot` 截图留存验证证据。

---

## 6. 检查清单

- [ ] 契约以类公开方法表达，未使用 `interface`；空值用 `null`。
- [ ] 原生未就绪时返回明确的降级值，**未伪造**结果。
- [ ] 平台差异用条件编译隔离，其他端仍可编译。
- [ ] 音频帧/口型未进入响应式状态；退出时释放资源。
- [ ] 改动已在真机（release 包）回归，或有明确的未验证标注。
- [ ] 新增/修改的纯逻辑有单测（若为纯函数部分）。
