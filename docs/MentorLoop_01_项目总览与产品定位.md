# MentorLoop AI 面试产品：项目总览与产品定位

## 1. 产品定义

MentorLoop 是一款面向求职者的移动端 AI 面试训练产品。用户从上传简历和选择目标岗位开始，进入由 AI 数字人主持的语音模拟面试；系统根据用户回答实时追问、记录证据并生成可执行的训练报告。

产品不是“题库播放器”，也不是“给答案的聊天机器人”。核心价值是把真实面试中的不确定性拆解为可重复训练的能力闭环：

```text
目标岗位与简历
→ 岗位能力画像
→ 个性化题目路径
→ 数字人语音面试与动态追问
→ 证据化评分报告
→ 薄弱点专项训练
→ 二次模拟与成长对比
```

## 2. 产品边界

- 独立设计：不继承现有 Web/Electron 的页面、流程、评分、交互或接口。
- 可利用但不直接展示：既有题库只能经内容专家人工审核、去重、标注和重构后，作为内部题目素材。
- 首发不做：真人招聘撮合、简历代投、公开点评社区、无边界职业咨询、第三方视频数字人。
- 首发聚焦：Java 后端 1–3 年经验岗位；题目结构和能力模型可扩展至 AI 应用工程师、前端、测试和其他垂类。

## 3. 目标用户与痛点

### 主用户

- 0–3 年经验的技术求职者；缺少真实面试机会，知道知识点但讲不出项目故事。
- 转行或跳槽用户；需要识别自身经历与目标岗位之间的能力缺口。
- 培训机构、院校就业中心；需要为学员提供可规模化的训练与能力反馈。

### 要解决的问题

| 用户问题           | 产品回答                                               |
| ------------------ | ------------------------------------------------------ |
| 不知道会被问什么   | 用岗位能力图谱决定题目而不是随机抽题                   |
| 回答后无人追问     | AI 根据用户的具体表述提出澄清、深挖和反例问题          |
| 不知道自己答得如何 | 评分必须引用回答证据，区分知识、表达、项目、推理和风险 |
| 练习后没有提升感   | 为每个薄弱点生成短周期训练任务和复测对比               |
| 简历与面试准备脱节 | 简历解析直接生成岗位画像、风险问题和改写建议           |

## 4. 核心差异化

1. **面试证据链**：报告不只给分数，必须说明“哪一句回答体现了什么能力或缺口”。
2. **有职业人格的数字人**：数字人是节奏、追问、非语言反馈和沉浸感的载体，不是播放一段视频。
3. **岗位化而非泛聊天**：以岗位胜任力和真实项目经历为中心，而不是万能问答。
4. **训练闭环**：报告自动变成 7/14 天训练计划，并在复测时显示增长。
5. **移动场景优先**：用户可随时完成 5 分钟快练或 20 分钟正式模拟。

## 5. 商业模式

- 免费层：简历体检一次、短面 1 次、基础报告。
- 单次包：完整模拟面试和详细报告。
- 订阅会员：多岗位、无限专项训练、成长档案、精品音色和高级报告。
- B 端：培训机构、院校与企业内训的席位订阅、班级看板与定制题库。

## 6. 分阶段目标

### 验证版（8 周）

微信小程序、Java 单一岗位方向、一个数字人角色、简历上传、10–15 分钟语音面试、基础报告。目标是验证用户是否愿意完成面试并为报告付费。

### 商业 MVP（4–5 个月）

小程序正式版 + Android/iOS Beta；简历优化、岗位画像、动态追问、专项训练、支付、运营后台、监控与隐私合规。

### 增长期（6–12 个月）

多岗位、多角色、多音色、机构版、题目运营系统、A/B 实验、精细化转化和复购运营。

## 7. 北极星指标

- 完成一次正式模拟面试的用户数。
- 面试完成率与报告查看率。
- 报告后 7 日专项训练完成率。
- 14 日内再次模拟率。
- 付费转化率、复购率和单场面试综合毛利。
