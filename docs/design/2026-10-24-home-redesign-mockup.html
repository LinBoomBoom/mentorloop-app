03 / 小屏 · 360×640 隐藏主卡描述、脚注与模块副标题，保留五层结构与全部入口；默认字号下首屏不滚动，大字号允许滚动兜底。

为什么这样改

  • 一个主行动。面试是最高频任务，只保留一个白色主按钮；训练、简历降为两列次级入口，但首屏必须同时可见。
  • 深 / 浅分区。上半屏是「任务舱」：深色、沉浸、只讲今天；下半屏是「训练纸」：浅色、清晰、可执行。重叠 30px 形成层次，不再是一摞白卡。
  • 闭环可视化。面试 → 报告 → 训练用一条轨迹线串起来；用户始终知道自己处在哪一步，而不是面对一堆互不相关的卡片。
  • 成长收成一条轨。累计场次、最近等级、最近报告压成一条细轨，替代三张统计卡，降低噪音，也为小屏腾出空间。

参考与取舍

参考 借什么 / 不借什么
Duolingo 单一主行动 + streak；不借卡通化与强游戏化。
Keep 「今日计划」+ 模块入口的结构；不借大面积课程货架。
牛客 / 面试鸭 刷题/训练是一级入口；不借信息密集的题库流。
Linear 安静层级、hairline 分割、克制的颜色；不借桌面密度。
shadcn/ui GitHub · 一致圆角、间距与对比度；不借默认中性灰审美。
cal.com GitHub · 开源产品里的信息密度与「下一步」清晰度；不借后台式布局。
dub.co GitHub · 指标条与轻量数据展示；不借仪表盘密度。

五态与红线

  • 空态：无报告 → 摸底任务；无训练任务 → 自选练习；文案不出现「暂无数据」。
  • 加载：成长轨用骨架行；主卡不整页 loading，避免首页闪白。
  • 失败：主卡保留，底部 toast + 重试；不阻断浏览训练/简历。
  • 降级：网络弱时隐藏最近报告，成长轨显示「报告待同步」。
  • 权限：匿名态登录提示收成一行，不弹全屏登录层。
  • 红线：首页不显示「实时评分」；评级必须标注来自最近报告；AI 批注始终标注为建议。
Alternative Direction B

备选方向 · 学习手账

更安静、更像一本学习手账：暖纸色、衬线标题、纵向时间线。适合后续 A/B 测试，但主行动不如 A 明确， 信息密度也更低。若选择 B，需要重新定义深色面试房间与浅色学习页的过渡。

评审问题

  • 主标题「把下一场面试，练成你的主场」是否符合产品语气？
  • 训练舱的深色比例是否过重？是否需要更轻的版本？
  • 「今日任务」与主卡是否存在重复？是否应合并成一张任务卡？
