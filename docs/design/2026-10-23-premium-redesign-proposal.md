## 1. 选型结论

| 维度       | 结论                                                                                    |
| ---------- | --------------------------------------------------------------------------------------- |
| 风格方向   | iOS「系统分组」语言：分组背景、白色卡片、发丝分隔线、大标题、克制的靛蓝强调             |
| 高级感来源 | 比例与留白、字号层级、单一强调色、少量深色沉浸面；不靠渐变堆叠、不靠毛玻璃特效          |
| 双面策略   | 深色沉浸只保留给首页主卡、会员卡、面试房间；其余为浅色学习面（沿用现有双面原则）        |
| 导航       | 由 4 Tab 收敛为 **3 Tab**：练习 / 成长 / 我的                                           |
| 面试房间   | 改为 **对话式聊天窗口**：AI 气泡流式出字 + 语音同步；用户可按住说话或直接打字           |
| 约束       | 不新增色板与字体；只调整现有 token 的值（需三载体同步），不引入图表库、不引入毛玻璃依赖 |

## 2. 信息架构与业务串联

### 2.1 导航调整

| 现状（4 Tab） | 改版（3 Tab） | 说明                                         |
| ------------- | ------------- | -------------------------------------------- |
| 首页          | 练习          | 只回答「现在开始练什么」                     |
| 专项训练      | 成长          | 与「结果」合并；报告 → 训练 → 再面试验证     |
| 结果          | 成长          | 报告作为成长的「证据面」，训练作为「行动面」 |
| 我的          | 我的          | 账号、手机号、会员、偏好、隐私               |

`pages.json` 的 tabBar 由 4 项改为 3 项；`pages/training/training.uvue` 与 `pages/report/report.uvue` 不再作为独立 Tab，改为「成长」页内分段与二级页。

### 2.2 闭环

```
首页（开始面试）
  → 面试房间（对话式作答）
  → 结束确认（二次确认）
  → 报告（六维 + 证据 + 优先改进）
  → 成长页（趋势 / 历史）
  → 训练（消费优先改进项）
  → 回到首页再练一场
```

所有入口都带明确的下一步动作；报告卡不再只展示分数，而是直接给出「优先改进」与「去训练」。

## 4. 面试房间对话化规格

### 4.1 布局（三段式，自下而上）

1. **顶部栏**：返回、AI 面试官 + 「系统生成」标识、题号 / 计时、结束。
2. **对话区**：可滚动消息流；AI 左侧白气泡、用户右侧靛蓝气泡；日期分隔；追问与「正在整理追问」状态。
3. **输入条**：按住说话 + 键盘切换 + 发送；录音时上方升起录制面板（计时 / 实时字幕 / 声波 / 取消 / 完成）。

### 4.2 消息模型（客户端）

```
ChatMessage {
  id: string
  role: 'ai' | 'user' | 'system'
  kind: 'question' | 'followup' | 'answer' | 'transcript' | 'notice'
  text: string
  status: 'streaming' | 'speaking' | 'done' | 'failed'
  editable: boolean          // 仅转写结果可编辑
}
```

- 题目仍来自现有接口，不需要服务端流式改造；客户端按播报进度逐字上屏，形成「流式」观感。
- TTS 不可用时不做假播放：直接把整段文字上屏，并标注「语音暂不可用，已切换文字」。
- 转写结果进入可编辑确认态；未确认不推进下一题（保留 2026-10-23 的确认修复）。

### 4.3 状态与颜色（沿用 token）

| 状态      | 颜色              | 非颜色提示                  |
| --------- | ----------------- | --------------------------- |
| 提问/追问 | `smart`           | 「AI 面试官 · 系统生成」    |
| 播报中    | `smart`           | 波形 + 「正在播报」         |
| 倾听/录音 | `reliable`        | 录制面板 + 计时             |
| 思考中    | `mist`            | 三点动画 + 「正在整理追问」 |
| 失败/降级 | `danger` / `mist` | 明示原因 + 文字模式出口     |

### 4.4 五态覆盖

| 状态   | 设计                                                 |
| ------ | ---------------------------------------------------- |
| 空态   | 首题未到：显示「正在准备第一题」骨架，不显示空聊天框 |
| 加载   | AI 气泡内三点动画；输入条禁用并保留解释              |
| 错误   | 气泡下方「重试」与「改用文字」两个出口               |
| 降级   | 无麦克风 / TTS 不可用：自动切文字模式，顶部常驻说明  |
| 无权限 | 麦克风权限被拒：说明 + 「去设置」+「先用文字作答」   |

### 4.5 硬规则保留

- 房间内不展示实时分数。
- 结束需二次确认（iOS action sheet）。
- 异常退出自动保存已答内容。
- 跳过保留回答作为证据。
- AI 不得伪装真人；所有 AI 消息带「系统生成」标识。

### 4.6 性能

- 字幕与声波按 10–15 次/秒节流，不进每帧响应式。
- 音频帧不放入响应式状态；退出时释放播放器与录音实例。
- 气泡动画只做透明度与位移，尊重 `prefers-reduced-motion`（全局已处理）。

## 6. 待确认项（附推荐）

| #   | 待确认                         | 推荐                                                                 |
| --- | ------------------------------ | -------------------------------------------------------------------- |
| 1   | 导航是否收敛为 3 Tab           | 推荐 3 Tab（练习 / 成长 / 我的）；若坚持保留训练独立入口，可做 4 Tab |
| 2   | 是否接受 token 值全局调整      | 推荐接受；否则只改局部会与组件圆角/描边漂移，难以形成统一高级感      |
| 3   | 面试房间用浅色聊天还是深色聊天 | 推荐浅色 iOS 聊天；深色只保留在准备页与结束过渡，降低长时间答题压迫  |
| 4   | 语音播报默认开启还是默认关闭   | 推荐默认开启，首题前给一次「静音练习」开关；文字始终同步             |

评审结论（2026-10-23）：3 Tab、token 全局调整、浅色聊天、语音默认开启可静音均确认。实施任务卡见 [2026-10-23-premium-redesign-implementation.md](../tasks/2026-10-23-premium-redesign-implementation.md)；P0–P1 不涉及契约，P2 复用现有接口，不新增契约。
