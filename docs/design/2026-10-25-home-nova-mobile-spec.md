## 3. 原语映射记录

| Web 原语               | 本项目替代                                      | 出现位置             |
| ---------------------- | ----------------------------------------------- | -------------------- |
| `gap-*` / `space-*`    | `mt-*` / `ml-*`                                 | 三卡、快捷入口、顶栏 |
| CSS grid               | `flex-row` + `flex-1` + 固定宽度                | 三卡仪表盘、2 列入口 |
| `bg-white/90` 透明度   | 内联 `rgba()` 或 `bg-surface`                   | 白卡                 |
| `backdrop-filter`      | App 可用；MP 用 94% 白 + hairline + shadow 模拟 | 顶栏                 |
| 内联 `<svg>`           | `ml-icon`（Lucide 子集）或预渲染 PNG            | 快捷入口、tab、声波  |
| `hover`                | `pressed-row` / `pressed-card` / `pressed-chip` | 卡片、快捷入口、CTA  |
| 22/18/16px 圆角        | `radiusCard`(20) / `radiusControl`(12)          | 主卡 → 20；白卡 → 20 |
| `radial-gradient` 球体 | 删除，改声波 PNG                                | 主卡右下             |
| 7–10px 微文案          | 实现统一 ≥12px                                  | 所有标签/辅助文案    |
| 大标题 30–39px         | 22px 标题 + 38px 仅用于主卡单个大数字           | 问候、主卡数字       |

**待冻结 token**：

- `heroGradient`: `linear-gradient(135deg, smart 0%, smartLight 100%)`；只组合现有 token，不新增 hex。
- `glassTop`: App `rgba(255,255,255,0.55)` + `blur(20px) saturate(170%)`；MP `rgba(255,255,255,0.94)` + `line` hairline。若后续复用，落为 `glassSurface` token。
- `displayMetric`: 38px 仅用于主卡大数字；现有字号白名单最高 28，需 PO 裁决。
- 声波资产：静态 PNG（透明底、蓝紫白低对比，建议 696×372 / 2x），由设计侧出；MP 与 App 共用一张，不做视频。
