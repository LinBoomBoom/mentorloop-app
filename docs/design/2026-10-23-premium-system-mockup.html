信息架构与业务串联

导航从 4 个 Tab 收敛为 3 个：首页负责「开始」，成长负责「看懂与改进」，我的负责「账号与权益」。 一次完整使用路径是：首页开始面试 → 面试房间对话式作答 → 结束生成报告 → 成长页查看证据与优先改进 → 进入训练 → 回到首页再练一场。

视觉体系 系统分组背景 + 白色卡片 + 发丝分隔线；大标题 28、卡片标题 17、正文 14/12。深色只用于首页主卡、会员卡与面试房间，形成「沉浸练习 / 轻盈学习」两种面。
为什么是 3 个 Tab 4 个 Tab 把「结果」和「训练」割裂，用户看完报告不会自然去练。合并为「成长」后，报告里的优先改进项可直接跳到训练，闭环更短。
落地约束 uvue 不支持毛玻璃与内联 SVG：Tabbar 用半透明白底 + 发丝描边模拟；趋势图用条形与数值实现，不引入新图表库；所有颜色与圆角仍走三载体 token。
