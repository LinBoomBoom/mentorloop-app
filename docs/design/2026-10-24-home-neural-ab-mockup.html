Comparison · A/B 怎么选

同一方向的两种性格

01A 更有机、更像「AI 神经核心」；01B 更数据化、更像「作战面板」，信息层级最清楚。 04A 用启动序列给足个性；06A/06B 最炫，但需要预渲染资产。推荐顺序：01B（最稳的科技感） → 01A（最强的 AI 记忆点）→ 04A（最有性格）。

版本 方向 核心差异 落地 适合
01A Neural Core 有机神经核心 + 轨道节点 + 实时读数 A 最像 AI 面试产品，主推候选
01B Tactical Radar 侧轨 + 战术雷达 + 六维条 A 科技感与信息清晰度最平衡
04A Boot Sequence 启动日志 + RUN 01 + 四格命令 A 最有个性，偏年轻技术人群
06A Holo Prism 3D 棱镜 + 六束光 + 全息板 C 最炫，需资产与性能预算
06B Wire Atom 线框原子球 + 三条轨道 + 节点 C 更轻、更像 AI 核心，需资产

我的建议

主推 01B Tactical Radar：它保留了你选中的 Neural Deck 语言，但把「今天下一步」做得最清楚， 六维数据也最有说服力；落地成本最低。

如果你要更强的「一眼 AI」记忆点，选 01A Neural Core；它更适合做品牌主视觉， 但要注意不要让六维节点盖过主按钮。

04A 适合做年轻化实验；06A/06B 适合做发布会/品牌页，不建议首发直接上实时 3D。
