01

CSS 材质打底 60%

毛玻璃、柔阴影、渐变网格、颗粒纹理。高级感主要来自图层关系，而不是颜色。

  • 玻璃：rgba 白 6.5% + blur 26 / saturate 150 + 1px hairline + 内侧高光
  • 阴影：24/60 柔阴影 + 内侧上下暗线，模拟真实材质
  • 背景：3 个径向渐变网格 + SVG 噪点，暗色也透气
02

动效呼吸感 MOTION

微交互、弹性动画、按压反馈；动效只确认操作，不做表演。

  • 主按钮 140ms scale 0.982 + 亮度变化
  • 半屏层 440ms cubic-bezier(.22,1,.36,1) 弹出
  • 页面元素 240ms 渐入；组件区滚动渐入；尊重 reduced-motion
03

Three.js 3D 空间 WEB

粒子场 + 漂浮几何体 + 视差背景。3D 在玻璃后面，不抢文字。

  • 1 个液态金属环结 + 2 个漂浮球 + 420 个粒子
  • 相机随指针/手指轻微视差；pixelRatio ≤ 1.5
  • 页面隐藏暂停；WebGL 不可用自动降级为渐变光斑
04

标准化组件系统 SYSTEM

按钮、卡片、列表、标签、状态全部同一套 token 与交互。

  • 3 种按钮 × 4 状态（默认/按压/禁用/加载）
  • 玻璃卡 / 列表行 / 标签 / 输入；触控 ≥ 44px
  • 空/加载/失败/降级/权限五态在下方组件区
Layer 04 · component system

Feasibility · web prototype vs uvue app

4 层在 App 端怎么落地

这个原型是设计目标，不代表客户端能原样跑。尤其第 3 层：uvue 不能运行 Three.js；必须用预渲染视频/PNG 序列或原生插件替代。第 1 层在 App 与小程序也有差异。下面是必须提前说清的边界。

层 Web 原型 uvue App 微信小程序
01 CSS 完整 glass / mesh / grain glass 可用 backdrop-filter（HBuilderX ≥5.25）；grain 用静态 PNG；mesh 用渐变；不能用 color-mix 无 backdrop-filter；用半透明高不透明底 + 细边 + 阴影模拟玻璃；grain 用 PNG
02 Motion CSS / JS 弹性动画 只用 transition / transform / opacity；按压用 `pressed-*`；无 spring 库 同 App；滚动渐入只在可滚动区域；首屏不做滚动动效
03 3D Three.js 实时渲染 不能直接跑 Three.js；用预渲染 MP4/PNG 序列 + 视差；或另立原生 3D POC 视频背景成本高；用静态海报 + CSS 光斑/视差，避免包体积与性能风险
04 Components 本页组件区 映射到 `ml-button` / `ml-card` / `ml-chip` / `ml-icon` + 五态组件 同 App；组件 props 走序列化，不传函数
