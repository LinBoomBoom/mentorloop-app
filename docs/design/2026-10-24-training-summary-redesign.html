这个页面的作用

  • 价值交付：用户刚花 5–10 分钟做题，先告诉他「练了什么、答得怎样」。
  • 复习闭环：模糊/不会的题立即给出「已进入错题本、明天复习」的预期。
  • 成长方向：用本组结果连接下一次练习，而不是停在数字上。
  • 下一动作：只给一个主行动，其余动作降级，避免按钮平铺。

信息顺序

本组结果 → 下一步建议 → 错题/SRS 预览 → 二级动作 → 返回。第一屏先回答「我这组怎么样」，再回答「我现在做什么」。

关键设计决定

  • 不用分数用「会 / 模糊 / 不会」计数和分段条，避免评分焦虑。
  • 动态主行动有错题时主按钮是「复习本组错题」；全对时切换为「再来 5 题」。
  • 错题露题面不只给数量；给题面摘要、细分领域和「明天复习」标签。
  • 去掉技术文案把「本机已记录」改为用户能理解的「只用于安排复习」。

uvue 落地映射

  • 结果卡：`ml-card` + 三段 `view` 进度条（flex 宽度按计数计算），不引入图表库。
  • 建议卡：浅紫底 `view` + `ml-button` 主/次按钮。
  • 错题卡：`ml-card` + 题面两行截断 + `ml-chip` 标签。
  • 动作：主按钮「复习本组错题」或「再来 5 题」；次按钮「换一组」。

需要覆盖的状态

  • 有错题 / 有模糊：主行动为错题复习。
  • 全对：空态 + 再来一组。
  • 0 题（异常）：提示返回做题页，不显示假数据。
