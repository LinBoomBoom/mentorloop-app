面试房间 · 对话式改版（设计稿 v1）

把「题目卡 + 语音面板」改为熟悉的聊天窗口：AI 提问以气泡流式出现并与语音同步，用户可以按住说话、也可以直接打字。 保留 AI 身份标识、无实时分数、结束二次确认、文本模式与实时字幕等硬规则。

流式文字 + 语音同步 语音 / 文字双输入 识别结果可编辑 无实时分数 结束二次确认

交互与状态说明

对话式房间不改变面试引擎与评分链路，只重做信息呈现：题目文本由现有接口返回，客户端按播报进度做逐字上屏（流式感）， 语音仍走现有 TTS / ASR 通道。所有气泡都保留「AI 生成」标识与文本可读性，语音不可用时自动降级为纯文字，不出现死路。

状态色（沿用 token） 提问 / 追问：smart 靛蓝；倾听 / 录音：reliable 青绿；思考：mist 中性；待机：中性。颜色始终配文字或波形，不单独表意。
打断与节奏 用户按下录音即停止播报并进入倾听；松开后进入转写确认，未确认不推进下一题。AI 追问前显示「正在整理追问」。
小屏与性能 对话区独立滚动，输入条固定底部；字幕与音量按 10–15 次/秒节流，声波与光标为轻量 CSS 动画，尊重减弱动效设置。
