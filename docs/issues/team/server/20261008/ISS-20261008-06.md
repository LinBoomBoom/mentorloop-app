# 云端 500 错误排查：h3 生产环境吞掉堆栈

## 问题现象

云端接口返回 500，响应体无错误信息，无法定位根因。本地复现正常。

## 问题分析

h3 生产环境的 `setErrorHandler` 会吞掉堆栈，只返回通用 500。错误信息不进响应体，无法从客户端侧诊断。

## 处理措施

临时将 handler 包裹 `try-catch`，把 `error.message` 返回在响应体中，部署一次定位根因，修复后移除临时包裹。

## 后续建议

- 云端 500 排查标准流程：临时 try-catch 返回 message → 定位 → 移除。
- 生产环境应配置服务端日志收集（如写入文件或日志服务），避免依赖响应体排障。
- 此诊断法已在团队内部共享，列入服务端排障经验。
