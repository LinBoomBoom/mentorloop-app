# MySQL 保留字作裸列名导致云端 ERROR 1064

## 问题现象

本地 SQLite 全绿，部署到 TDSQL-C（MySQL 5.7 兼容）后查询报 `ERROR 1064 (42000): You have an error in your SQL syntax`。触发列：`desc`、`explain`。

## 问题分析

`desc` 与 `explain` 是 MySQL 保留字，出现在 SELECT / INSERT 列清单中时，mysql2 驱动抛出语法错误。SQLite 无保留字限制，故本地测试全部通过。`db-driver` 的 `translateSql` 仅转换双引号标识符，不处理裸保留字。

## 处理措施

对所有保留字列名加反引号（`` `desc` ``、`` `explain` ``），SQLite 同样接受反引号，本地与云端行为一致。已在受影响的 SELECT / INSERT 语句中修正。

## 后续建议

- 新增列命名时避开 MySQL 保留字，或一律加反引号。
- 建议在服务端 SOP 增加「云端数据库兼容」检查项：列名/表名是否命中 MySQL 保留字。
