# `rows.map(async ...)` 缺少 `Promise.all` 导致 Promise 数组被序列化为 `{}`

## 问题现象

M1 codemod 引入后，考试列表、答题历史、学习统计、模块详情、后端题库多个功能数据异常（返回空对象或结构错误）。

## 问题分析

M1 codemod 批量改写时，将 `rows.map(async (row) => ...)` 直接返回，未包裹 `Promise.all`。Nitro 序列化时 Promise 数组被序列化为 `{}`，导致多 feature 同时故障。

## 处理措施

在所有 `rows.map(async ...)` 外层补 `Promise.all`，恢复数据结构。已逐 feature 修复并通过云测验证 11/11。

## 后续建议

- codemod 涉及 `async` 回调时必须人工复核 `Promise.all` 包裹。
- 建议为 `map(async)` 模式增加 lint 规则或测试断言，防止回归。
