# `db.ts` 顶层 await 导致 Nitro esbuild 构建失败

## 问题现象

`db.ts` 第 1544 行使用顶层 `await`，Nitro 构建时 esbuild 目标为 es2019，构建失败。

## 问题分析

better-sqlite3 是完全同步的库，无需异步打开。顶层 `await` 在 es2019 目标下不被支持。

## 处理措施

将 `createDb` 改为同步打开（`new Database(...)` 直接同步执行），移除顶层 `await`。构建恢复正常。

## 后续建议

- better-sqlite3 操作一律同步，不使用 `async/await`。
- 新增数据库初始化代码时确认构建目标与语法兼容性。
