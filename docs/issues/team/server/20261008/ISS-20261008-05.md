# `insertUser` 异步调用缺少 `await` 导致注册流程 401

## 问题现象

注册流程中部分 `insertUser` 调用未加 `await`，导致后续逻辑在数据未写入时执行，引发 401 错误。

## 问题分析

三处 `insertUser` 调用点遗漏 `await`，异步操作未完成即继续执行，读取不到刚插入的用户数据。

## 处理措施

为全部 3 个 `insertUser` 调用点补充 `await`，注册流程恢复正常。

## 后续建议

- 所有数据库写操作必须 `await`。
- 建议在 service 层对返回 Promise 的调用增加静态检查或代码审查关注点。
