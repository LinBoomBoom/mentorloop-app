# MentorLoop AI 面试产品方案文档索引

生成日期：2026-09-19

本套文档基于已确认的产品方向整理：独立设计移动端 AI 数字人面试产品，不沿用既有 Web 或 Electron 端的页面、交互、面试编排、评分模型或接口设计。现有系统中的历史题目仅可作为后续人工审核后的内容素材。

## 文档清单

1. `MentorLoop_01_项目总览与产品定位.md`：产品定位、目标用户、商业模式、阶段目标。
2. `MentorLoop_02_主体功能与AI面试引擎.md`：完整功能设计、题目选择、追问、评分、报告和数字人方案。
3. `MentorLoop_03_UI_UX设计方案.md`：信息架构、页面、视觉系统、关键交互和无障碍要求。
4. `MentorLoop_04_uniappx技术架构与可行性.md`：uni-app x、UTS、后端、数据、安全、性能及测试方案。
5. `MentorLoop_05_研发交付运营与多Agent协同.md`：里程碑、角色职责、测试、运营、数据指标和 Agent 协同规范。
6. `MentorLoop_06_预算合规与上线清单.md`：从零开办、备案、账号、研发、云资源、AI 用量及资金方案。

## 已冻结的关键决策

- 形态：微信小程序优先，同一套 uni-app x 代码库支持 Android 与 iOS App；App 以 Beta 方式跟随小程序首发节奏。
- 数字人：自研 2.5D 面试官，采用角色资产、动画状态机、音素口型与情绪驱动；MVP 不采购第三方视频数字人 SaaS。
- AI：独立设计岗位能力画像、面试图谱、追问策略、评分量表和报告体系。
- 首发人群：1–3 年工作经验的 Java 后端求职者；后续扩展其他技术岗位与考学/考问场景。
- 技术：业务和 UI 跨端统一；实时音频、设备控制、数字人渲染以 UTS 原生插件隔离平台差异。
- 推荐资金：正式商业 MVP（含首 6 个月运行）建议准备 75–105 万元；推荐按 90 万元安排。

## 阅读顺序

先读 01 和 02 明确“做什么”，再读 03 和 04 决定“体验与实现”，最后用 05 和 06 组织“如何交付、需要多少钱”。
