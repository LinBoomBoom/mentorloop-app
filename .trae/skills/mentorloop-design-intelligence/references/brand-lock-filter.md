# 品牌锁过滤器（brand-lock filter）

所有候选（风格方向、配色、字体、布局、第三方参考）进入选型单前必须全项通过本过滤。目的：防止「灵感层污染约束层」——历史上第三方默认色板（如 `#ea580c`/`#2563eb`）与拉丁 webfont 正是设计文档冲突的成因。

## 红线（一票否决）

1. **0 个新色值**：任何色值必须等于 `main.css @theme` 中的既有 token。第三方色板（shadcn / MUI / Ant / Dribbble 截图 / 品牌官网取色）一律先映射：找语义等价的现有 token（如第三方「primary 蓝」→ `smart`；「success 绿」→ `reliable`），映射不上 → 剔除。
2. **0 个新字体**：唯一字体是 `--font-sans` 中文优先系统栈。任何 webfont / 衬线体 / 拉丁展示字体建议（Lora / Raleway / Inter…）→ 直接剔除；层级感用字号 + 字重表达。
3. **禁 Web-only 范式**：hover 态 / cursor / 响应式断点 / 透明度修饰符（`bg-white/5`）/ `gap-*`、`space-*` / 内联 `<svg>` / 后代选择器——候选中一律不得出现；对应替代：`pressed-*` 三档按压、rpx + 显式间距、`rgba()` 内联、`mt-*`/`ml-*`、Lucide 子集图标字体、扁平原子类。
4. **不越层**：候选不得包含 uvue 布局代码、交互流程、IA 结构；不得定义新 token（新 token 走三载体一次改齐的变更流程）。
5. **不越权**：选型单是咨询产物，未经 `mentorloop-role-uiux-designer` 确认不得当作设计规范引用。

## 过滤步骤

1. 列出候选中的**每一个**具体取值：色值、字体、动效时长、圆角、阴影、组件。
2. 逐项问：它是否等于某个现有 token？
   - 是 → 写 token 名，通过。
   - 否但语义可映射 → 映射到现有 token，通过（记录「来源值 → token」）。
   - 否且映射不上 → 剔除，记录剔除理由。
3. 检查范式违例（红线 3）→ 替换为项目范式或剔除。
4. 把结果写入选型单 §6 过滤记录：通过 / 映射 / 剔除，三态留痕。

## 常见违例速查

| 违例来源             | 典型形态                             | 处置                                      |
| -------------------- | ------------------------------------ | ----------------------------------------- |
| 第三方组件库默认色板 | `#2563eb` primary / `#ea580c` accent | 映射 `smart` / `warn`，或剔除             |
| 拉丁 webfont         | Lora / Raleway / Inter               | 剔除，用 `--font-sans` + 字重分层         |
| 设计网站灵感图       | 任意渐变、玻璃拟态、霓虹色           | 拆解为现有 token 组合，拆不出 → 剔除      |
| Web 交互范式         | hover 卡片抬升、`@media` 断点        | 改 `pressed-*` 按压；单移动尺寸 rpx       |
| Tailwind Web 语法    | `bg-white/5`、`gap-4`、`<svg>`       | 内联 `rgba()`；`mt-*`/`ml-*`；Lucide 字体 |

## 记录要求

过滤记录必须可复核：每项写「检查结果 + 处置」，剔除项写明来源。未过过滤器的候选不得出现在选型单 §2/§3/§5 的正式表格中。
