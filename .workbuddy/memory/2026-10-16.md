## 3. 关键环境事实（换机必读，避免重复排查）

1. **DevTools 只导入 `dist/` 下的产物**（`dist/dev/mp-weixin` 或 `dist/build/mp-weixin`）。`unpackage/dist/**` 是 **HBuilderX** 的运行产物，**禁止导入** —— 它把全部页面样式聚合进根 `app.wxss`，注入的 `@import "../../uvue.wxss"` 相对路径越界 → `[WXSS 文件编译错误] path '../../uvue.wxss' not found`、全页样式失效。已登记 [ISS-20261011-01](../../docs/issues/team/miniprogram/20261011/ISS-20261011-01.md)。两个路径都以 `dev/mp-weixin` 结尾，极易开错。
2. **HBuilderX 只用于 App 端真机调试**；MP 端开发循环固定为 `pnpm dev:mp-weixin`（watch）+ DevTools 导入 `dist/dev/mp-weixin`。
3. **小程序热重载不会重跑页面 `<script setup>`**（只更新模板）→ 改完逻辑若「没生效」，先 `cli close` + `cli auto` 重开项目再判断，否则会误判成代码问题。
4. **Python/Node 内联脚本勿用 PowerShell `node -e`**（引号与 `[` `]` 会被解析破坏）→ 写临时 `.mjs` 再跑。
5. **自动化 E2E 前置**：DevTools → 设置 → 安全设置 → 服务端口「开启」（已开，端口 45856）；再 `cli.bat auto --project dist\build\mp-weixin --auto-port 9420 --trust-project`，然后 `pnpm test:mp --no-build --ws=ws://127.0.0.1:9420`。
6. 本机**无 HBuilderX 参与构建**；客户端 `pnpm typecheck` 在 CI 里是 `continue-on-error`（需 HBuilderX 环境）。
7. 自动化连接偶发被沙箱拦（写 `微信开发者工具\User Data\...\.cli`）→ **偶发，重试即可**，不需要改权限配置。
